# TME Aquarium v2.0.0

一个离线优先、可复现的肿瘤微环境机制教学与实验平台。它把二维空间模拟、实验基线对照、空间探针、研究任务和证据边界说明整合在同一界面中。

> 本项目只用于机制教学、课堂演示与假设探索。所有时间、距离、场强、阈值、概率和干预强度均为模型单位或代理指标，不可用于诊断、处方、患者预测或临床决策。

## 功能特性

- **空间模拟**：96×60 网格上的肿瘤—免疫—基质生态，含血管供氧、扩散、拥挤、克隆选择、细胞杀伤、碎片清除与基质重塑。
- **实验工作台**：捕获基线、记录实验笔记、比较干预前后指标，并导出 Markdown 实验记录。
- **空间探针**：点击地图读取局部氧气、药物、基质、抑制、急性炎症与慢性炎症压力。
- **七大地图图层**：细胞 / 氧气 / 药物 / 基质 / 抑制 / 急性炎症 / 慢性炎症，附色觉友好色标与低氧代理边界。
- **双炎症场**：区分短程急性激活代理与较慢变化的慢性炎症压力代理。
- **T 细胞状态分层**：前体样（stemlike）与终末耗竭样（terminal exhaustion）连续代理维度。
- **显式低氧方向感知**：巨噬细胞运动规则可响应局部低氧梯度。
- **新指标体系**：克隆多样性、免疫排斥、灌注异质性、坏死碎片比例等。
- **引导实验与研究任务**：用“提出问题—固定基线—改变变量—观察空间证据—解释边界”的流程引导学习。
- **可复现**：固定随机种子，相同设置得到相同结果。
- **可访问性**：色觉友好模式、减少动效模式、键盘焦点与表单标签完整。
- **离线可用**：Service Worker 预缓存全部资源，可作 PWA 安装。

## 快速开始

项目不依赖第三方运行时包。推荐使用本地静态服务器：

```bash
npm start                 # 即 python3 -m http.server 4173
# 或手动：
python3 -m http.server 8080
```

然后在浏览器打开 `http://localhost:4173/`（或 `http://localhost:8080/`）。直接双击 `index.html` 也可查看大部分功能，但 Web Worker、Service Worker 或浏览器安全策略可能限制部分行为。

## 部署（Cloudflare Pages / 任意静态托管）

本项目是纯静态站点，无构建步骤：

- **构建命令**：留空（或任意无害命令）
- **构建输出目录**：`/`（仓库根目录）
- `_headers` 会被自动读取，提供 CSP、`X-Frame-Options` 等安全头
- 更新代码后推送到 `main` 分支，Cloudflare Pages 自动重新部署

## 验证

```bash
npm run verify
```

验证流程包括：

1. 证据导出（`npm run evidence`）——生成 `docs/机制证据登记_v2.0.csv`、`docs/参考文献_v2.0.csv`、`docs/references.bib`；
2. Node 单元测试（`npm test`）；
3. 六场景、单参数方向与治疗弧审计（`npm run audit`）——结果写入 `docs/场景校准与敏感性审计.md`；
4. 静态完整性审计（`npm run check`）——HTML DOM 引用、图层、外链安全、JavaScript 语法和 Service Worker 资源完整性。

## 科学依据与边界

- 每个模型机制都在 `src/evidence.js` 中登记证据层级、模型翻译与不可外推部分；应用内“证据与边界”面板可查看。
- 完整科学说明见 `SCIENCE_MODEL_NOTES_v2.0_zh-CN.md`。
- 详细变更见 `CHANGELOG_v2.0.md`；从 v1.x 升级见 `UPGRADE_GUIDE_v2.0_zh-CN.md`。
- 模型是机制教学工具，未经外部数据集拟合，未提供置信区间或临床验证。

## 推荐教学流程

1. 选择场景并运行至稳定观察窗口。
2. 捕获基线，写下假设。
3. 切换至少三个空间图层并使用探针采样。
4. 只改变一个参数或施加一次干预。
5. 比较代理指标与空间分布，而不是只看总癌细胞数。
6. 导出实验记录，并明确写出模型未包含的机制和替代解释。
