# TME Aquarium v1.1｜肿瘤微环境生态缸

TME Aquarium 是一个完全运行在浏览器中的二维 Agent 肿瘤微环境生态模拟器。v1.1 在原有癌细胞、T 细胞、血管、缺氧、药物和基质系统上，加入巨噬细胞、成纤维细胞 / CAF、炎症与血管支持场、机制证据追踪和更严格的存档安全边界。

> 本项目是证据约束的机制性教育模拟，不用于疾病诊断、药物选择、治疗决策、剂量设计、患者预后预测或任何临床用途。当前参数是归一化的演示参数，未经过患者数据、实验数据或癌种特异数据拟合。

## v1.1 主要能力

- 6 个预设生态场景，均初始化癌细胞、T 细胞、巨噬细胞、成纤维细胞和血管。
- 三类癌细胞克隆：高增殖敏感型、慢增殖耐药型、缺氧耐受型。
- T 细胞趋化、攻击、能量消耗、耗竭及基质/抑制场限制。
- 巨噬细胞连续功能轴 `[-1, 1]`、募集、趋化、碎片吞噬、吞噬记忆、炎症/抑制输出和低氧相关血管支持。
- 成纤维细胞 / CAF 的活化、基质沉积和免疫排斥程序。
- 氧气、药物、基质、免疫抑制、炎症、血管支持和克隆图层。
- 细胞毒性治疗、免疫激活、局部供氧、巨噬细胞功能重编程和基质正常化。
- 治疗初始反应、克隆替代和治疗后反弹事件。
- 单细胞检查器、缩放、拖拽、暂停、逐步推进和多档速度。
- 16 条机制证据卡与 23 篇核心参考文献的页面内溯源。
- 浏览器本地存档、JSON 导入导出、CSV、PNG 和分享码。
- v2 存档格式、v1 向 v2 迁移、8 MB 导入上限、字段/数组/ID/数值校验和 Worker 消息白名单。
- 固定随机种子和可重复模拟。

## 本地运行

要求 Node.js 20 或更高版本。项目无第三方运行时依赖。

```bash
npm start
```

然后访问 `http://localhost:4173`。

也可以使用任意静态 HTTP 服务器托管项目根目录。不要直接以 `file://` 打开，因为浏览器通常会限制 ES Module Worker 和 Service Worker。

## 自动验证

```bash
npm test
npm run audit
```

`npm test` 当前包含 15 项测试，覆盖：

- 旧版主闭环回归与固定种子复现；
- 六场景新增实体初始化；
- 新字段范围与新增实体确定性；
- 巨噬细胞吞噬和功能重编程；
- CAF 基质沉积和基质正常化；
- 高基质对药物暴露与 T 细胞移动的方向性影响；
- v1 存档迁移、v2 恢复及恶意/损坏输入拒绝；
- 六场景中期运行不发生明显参数崩溃。

`npm run audit` 会重新生成 `docs/场景校准与敏感性审计.md`。该审计只检查数值稳定性、方向错误和治疗弧，不代表实验或临床校准。

## 存档兼容与安全

- 当前存档版本：`2`；模型版本：`1.1.0`。
- 可读取 v1 存档；迁移时保留旧癌细胞、T 细胞、碎片和历史，并按当前场景补入 v1.1 的巨噬细胞与成纤维细胞。
- 导入会检查文件大小、版本、字段形状、环境数组长度、有限数、范围、坐标、实体上限及 ID 唯一性。
- 未知 Worker 消息、非法参数和未知干预会被拒绝。
- 导入数据和事件文本通过 DOM `textContent` 呈现，避免直接拼接为 HTML。

## 静态部署

Cloudflare Pages 等静态托管平台不需要构建步骤：

- Build command：留空；平台强制要求时可使用 `echo "static site"`。
- Build output directory：项目根目录 `/`。
- 保留项目根目录下的 `_headers`，以启用 CSP、`nosniff`、点击劫持防护和权限限制。

部署后建议验证：首次加载、刷新、离线缓存更新、Web Worker、全部图层、五种干预、证据页、v1/v2 存档导入，以及窄屏布局。

## 模型边界

当前规则强调可见、可解释的生态关系，而非生物物理或临床精度。药物、毒性、供氧、免疫抑制、炎症和血管支持均为归一化抽象量；模型不包含真实药代动力学、剂量换算、完整细胞因子网络、患者级异质性或临床推荐范围。文献支持的是机制方向，不自动证明每个当前系数、阈值或场景参数为真实值。
