# TME Aquarium v2.0.0

一个离线优先、可复现的肿瘤微环境机制教学与实验平台。它把二维空间模拟、实验基线对照、空间探针、研究任务和证据边界说明整合在同一界面中。

> 本项目只用于机制教学、课堂演示与假设探索。所有时间、距离、场强、阈值、概率和干预强度均为模型单位或代理指标，不可用于诊断、处方、患者预测或临床决策。

## v2.0 的核心变化

- **实验工作台**：捕获基线、记录实验笔记、比较干预前后指标，并导出 Markdown 实验记录。
- **空间探针**：点击地图读取局部氧气、药物、基质、抑制、急性炎症与慢性炎症压力。
- **双炎症场**：区分短程急性激活代理与较慢变化的慢性炎症压力代理。
- **T 细胞状态分层**：在总体功能障碍之外，增加前体样与终末耗竭样代理维度。
- **显式低氧方向感知**：巨噬细胞运动规则可响应局部低氧梯度。
- **新指标体系**：克隆多样性、免疫排斥、前体样/终末耗竭样 T 细胞比例、灌注异质性、坏死碎片比例等。
- **研究任务**：用“提出问题—固定基线—改变变量—观察空间证据—解释边界”的流程引导学习。
- **可访问性**：色觉友好模式、减少动效模式、清晰图层色标和低氧代理边界。
- **存档 v3**：自动迁移 v1/v2 存档；新存档携带 v2.0 模型状态。

## 运行

项目不依赖第三方运行时包。推荐使用本地静态服务器：

```bash
python3 -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080/`。直接双击 `index.html` 也可查看大部分功能，但 Worker、PWA 或浏览器安全策略可能限制部分行为。

## 验证

```bash
npm run verify
```

验证流程包括：

1. Node 单元测试；
2. 六场景与单参数方向审计；
3. HTML DOM 引用、图层、外链安全、JavaScript 语法和 Service Worker 资源完整性检查。

场景审计文档会写入 `docs/场景校准与敏感性审计.md`。

## 目录

- `index.html`：主界面。
- `styles.css`：响应式与可访问性样式。
- `src/simulation.js`：空间模型与指标。
- `src/renderer.js`：地图、图层和空间探针。
- `src/app.js`：实验工作台、任务、导出和 UI 控制。
- `src/state.js`：存档验证与版本迁移。
- `src/evidence.js`：机制—证据—模型翻译—边界登记。
- `tests/`：状态、模型和 v2.0 回归测试。
- `scripts/`：场景审计与静态完整性审计。
- `docs/`：科学说明、升级指南和校准审计。

## 推荐教学流程

1. 选择场景并运行至稳定观察窗口。
2. 捕获基线，写下假设。
3. 切换至少三个空间图层并使用探针采样。
4. 只改变一个参数或施加一次干预。
5. 比较代理指标与空间分布，而不是只看总癌细胞数。
6. 导出实验记录，并明确写出模型未包含的机制和替代解释。
