# TME Aquarium

一个离线优先、可复现的肿瘤微环境机制教学与实验平台。它把二维空间模拟、实验基线对照、空间探针、研究任务和证据边界说明整合在同一界面中。

> 本项目只用于机制教学、课堂演示与假设探索。所有时间、距离、场强、阈值、概率和干预强度均为模型单位或代理指标，不可用于诊断、处方、患者预测或临床决策。

## 主要功能

- **空间模拟**：96×60 网格上的肿瘤—免疫—基质生态，含血管供氧、扩散、拥挤、克隆选择、细胞杀伤、碎片清除与基质重塑。
- **实验工作台**：捕获基线、记录实验笔记、比较干预前后指标，并导出 Markdown 实验记录。
- **空间探针**：点击地图读取局部氧气、药物、基质、抑制、急性炎症与慢性炎症压力。
- **九大地图图层**：细胞 / 氧气 / 药物 / 基质 / 抑制 / 急性炎症 / 慢性炎症 / 血管生成 / 克隆，附色觉友好色标与低氧代理边界。
- **双炎症场**：区分短程急性激活代理与较慢变化的慢性炎症压力代理。
- **T 细胞状态分层**：前体样（stemlike）与终末耗竭样（terminal exhaustion）连续代理维度。
- **显式低氧方向感知**：巨噬细胞运动规则可响应局部低氧梯度。
- **新指标体系**：克隆多样性、免疫排斥、灌注异质性、坏死碎片比例等。
- **引导实验与研究任务**：用「提出问题—固定基线—改变变量—观察空间证据—解释边界」的流程引导学习。
- **可复现**：固定随机种子，相同设置得到相同结果。
- **可访问性**：色觉友好模式、减少动效模式、键盘焦点与表单标签完整。
- **离线可用**：Service Worker 预缓存全部资源，可作 PWA 安装。

## 界面风格

工作台采用 `ydchen-portfolio` 的暖米白、浅灰与赤陶色视觉系统，使用衬线标题和扁平化控制面板；空间模拟、画布图层、存档和证据登记保持不变。

可读性基线为正文 16px、操作标签不小于 12px；深色模拟画布使用独立高对比度文字令牌，桌面与手机端均不得出现全局横向溢出。

本项目为普通项目类。页眉桌面 72px、手机（≤640px）64px；方章 48×48px / 40×40px，标题衬线 18px/400/1.3、手机 16px，副标题无衬线 12px/400/1.4；标志与标题间距 12px，标题与副标题间距 2px。

页眉内容区最大宽度 1280px（含两侧各 16px 内边距），整体居中；品牌和标题靠左，操作区靠右，窄屏换行后仍保持该对齐。品牌页眉在文档顶部正常排布，随页面滚走，不固定或吸顶；表格内部表头、侧边工具和手机底部导航可按功能保留。

正文采用统一系统无衬线字体，默认 16px / 1.6；标题采用 Georgia、Times New Roman、Songti SC、STSong 衬线族。数字与代码可使用 SFMono-Regular、Consolas、Liberation Mono、Microsoft YaHei 等宽族。按钮和输入通常 15px，辅助文字 12–14px，密集科学数据允许有理由的局部调整。页面底色 #f3eee5、正文 #24221f、赤陶强调 #a94f31，柔和底色上的强调文字 #823a25；科学分类色、热图、作品主题与状态色保留必要区分度。

## 数据与隐私

本项目是纯静态站点，业务数据保存在浏览器本地。具体说明：

- 模型机制全部登记在应用内「证据与边界」面板中，可查看每个机制的证据层级、模型翻译与不可外推部分。
- 存档与实验记录默认保留在本地，可导出为 Markdown 实验记录。
- 模型是机制教学工具，未经外部数据集拟合，未提供置信区间或临床验证。

## 本地运行

项目不依赖第三方运行时包。推荐使用本地静态服务器：

```bash
npm start                 # 本地静态预览（http://localhost:4173）
# 或手动：
python -m http.server 4173
```

然后在浏览器打开 `http://localhost:4173/`。直接双击 `index.html` 也可查看大部分功能，但 Web Worker、Service Worker 或浏览器安全策略可能限制部分行为。

## 部署

本项目是纯静态站点，无构建步骤，可部署到 Cloudflare Pages 或任意静态托管：

- **构建命令**：留空（或任意无害命令）
- **构建输出目录**：`/`（仓库根目录）
- `_headers` 会被自动读取，提供 CSP、`X-Frame-Options` 等安全头
- 更新代码后推送到 `main` 分支，Cloudflare Pages 自动重新部署

## 责任边界

本项目只用于机制教学、课堂演示与假设探索，所有时间、距离、场强、阈值、概率和干预强度均为无量纲、归一化的模型系数或代理指标，不映射真实浓度、剂量、时间或 pO₂ 阈值，不可用于诊断、处方、患者预测或临床决策。

## 维护与兼容

手机顶栏分行展示场景、运行和辅助操作。画布可聚焦，方向键移动空间探针，Shift 加速，Enter 选取，Escape 清除。

关键事件时间轴按内容确定高度，初始化事件的标题和说明可以完整显示；多事件在时间轴内部横向滚动。

品牌页眉与运行控制区分行；时间轴高度随内容增长，初始化事件卡不再裁切。读取存储失败可提示。新增默认种子与六场景多种子存档回归：巨噬细胞血管入口生成抖动允许 y 最低为 -0.4，恢复保持原坐标和后续轨迹；不改变模型计算或版本。

桌面参数和结果使用整页滚动；画布保留合理高度，初始化时间轴完整显示。

检查命令与技术约束见 [AGENTS.md](./AGENTS.md)。上述浏览器验证描述对应 2026-09-13 的维护验收；后续修改仍须重新验证。
