# v1.1 模型变更记录

## 发布定位

v1.1 将 TME Aquarium 从“癌细胞—T 细胞—血管”演示扩展为包含髓系和间质反馈的证据约束教育模拟。该版本仍是机制性沙盒，不是实验数据拟合模型或临床预测工具。

## 新增实体

### 巨噬细胞

- 独立 Agent 集合和场景化初始数量/募集强度。
- 连续功能轴 `activation ∈ [-1, 1]`，避免把巨噬细胞硬分为静态 M1/M2 两类。
- 响应坏死碎片、炎症、低氧和免疫抑制的空间梯度。
- 吞噬死亡碎片并积累 `efferocytosisMemory`。
- 根据局部状态输出炎症、免疫抑制和血管支持信号。
- 可通过“巨噬细胞功能重编程”短时把群体功能轴推向炎症支持侧，但不删除细胞。

### 成纤维细胞 / CAF

- 独立 Agent 集合和场景化初始数量/活化倾向。
- `activation`、`matrixActivity`、`exclusionActivity` 三个维度。
- 局部基质沉积、免疫排斥和抑制场反馈。
- 可通过“基质正常化”降低过量沉积和排斥，但不删除 CAF，也不把基质清零。

## 新增环境场与可视化

- 炎症信号 `inflammation`。
- 血管支持信号 `angiogenic`。
- 新增两类图层、色标、巨噬细胞和 CAF 绘制、命中测试、悬停提示和单细胞检查器。
- 新增巨噬细胞功能轴、吞噬计数、CAF 活化与平均基质等指标。

## 场景与模型修正

- 六个场景加入巨噬细胞和成纤维细胞参数及保守默认值。
- 增加场景 schema、范围和克隆比例校验。
- 修正“缺氧耐受越高反而氧需求越高”的方向问题。
- sparse/rim 血管位置改为靠近肿瘤，而非世界边界。
- 初始氧场改为基于血管距离的梯度。
- 药物、炎症和血管支持采用不同的基质扩散惩罚。
- 死亡原因、碎片炎症和吞噬记忆进入快照与存档。

## 新增干预

- 巨噬细胞功能重编程。
- 基质正常化。
- 原有细胞毒性治疗、免疫激活和局部供氧继续保留。

## 证据治理

- 页面内接入 16 条机制溯源卡和 23 篇核心参考文献。
- 每条机制记录证据层级、文献摘要、模型翻译方式、适用边界和不可外推项。
- 明确区分“文献支持的机制方向”和“尚未校准的归一化数值参数”。
- CAF 不被定义为单一促瘤实体，并保留基质可能限制肿瘤扩张的反例边界。

## 存档与安全

- 存档版本升级为 v2；模型版本为 `1.1.0`。
- 支持读取和迁移 v1 存档。
- 加入 8 MB 导入大小限制。
- 校验数组长度、有限数、范围、坐标、实体数量、ID 唯一性、版本和消息类型。
- Worker 使用消息白名单，未知干预和非法参数被拒绝。
- 导入内容使用 `textContent` 呈现，不直接注入 HTML。
- Service Worker 缓存升级为 `tme-aquarium-v1.1.0`，并缓存新增模块。
- 增加 CSP、`nosniff`、权限限制、COOP 和点击劫持防护响应头配置。

## 测试与审计

自动测试从 4 项扩展为 15 项，新增覆盖：

- 六场景新增实体初始化；
- 新实体和新字段的固定种子复现与范围约束；
- 巨噬细胞碎片吞噬、吞噬记忆与功能重编程；
- CAF 基质沉积和基质正常化边界；
- 高基质对药物暴露和 T 细胞移动的方向性影响；
- v1 迁移、v2 恢复及损坏/恶意存档拒绝；
- 六场景中期运行稳定性。

另增加六场景中期运行、四个单参数扫描和三档基质下治疗反应—反弹检查。结果只用于内部一致性审计，不构成生物学真实性证明。
