- 验证日期：2026-08-03

## 数值与场景审计

执行：

```bash
npm run audit
```

结果摘要：

- 六个场景在 600 步、2 个固定种子的中期窗口内均保留活癌细胞和 CAF，没有出现明显参数崩溃。
- 对供氧、基质、巨噬细胞募集和成纤维细胞活化进行了单参数扫描。
- 基质参数 20、42、80 三档下均观察到治疗后初始下降和随后反弹事件。
- 完整结果见 `场景校准与敏感性审计.md`。

这些结果只验证内部数值稳定性和预期方向，不代表实验拟合、癌种特异校准或临床有效性。

## 浏览器 smoke test 状态

本环境安装了 Chromium，但系统级托管策略包含全局 URL 阻止规则 `URLBlocklist: ["*"]`。因此，无论访问本地 HTTP 地址还是 `file://`，浏览器都会显示组织策略阻止页面，无法在不绕过安全策略的前提下完成真实页面加载、Worker、图层和交互验证。

这是一项**环境阻塞**，不是已经观察到的应用运行错误。没有修改、规避或删除该机器策略。

发布前仍建议在未受该策略限制的浏览器中验证：

1. 首次加载与刷新后 Service Worker 更新。
2. 启动、暂停、逐步推进和四档速度。
3. 六个场景及七个环境/克隆图层。
4. 巨噬细胞和 CAF 的绘制、悬停、点击检查。
5. 五种干预、事件流、指标和趋势图。
6. 证据与文献页签及外链。
7. v1/v2 存档、损坏存档拒绝、CSV/PNG/JSON 导出。
8. 桌面和窄屏布局。

## Cloudflare Pages 状态

本环境未提供目标账户、预览项目或部署凭据，因此未执行线上预览部署。项目保持纯静态结构，无构建依赖；部署参数和回滚步骤见 `发布与回滚.md`。

## 已知科学限制

- 没有外部实验数据集拟合或交叉验证。
- 没有癌种特异参数、真实剂量或药代动力学。
- 没有全局敏感性分析、不确定性区间或患者级预测。
- 文献支持机制方向，不支持把当前归一化参数解释为临床量值。
