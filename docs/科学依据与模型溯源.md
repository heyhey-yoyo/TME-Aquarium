# TME Aquarium v1.1：科学依据、模型溯源与参数边界

> 本文档说明每个主要模拟模块为什么存在、由什么证据支持、如何被翻译成计算规则，以及不能从模拟中推出什么。它不是临床模型验证报告。

## 1. 科学性标准

本项目把“科学性”拆成五个可检查层级：

1. **机制来源**：每条生物规则必须能追溯到原始研究或明确标注为模型假设。
2. **证据类型**：区分人体组织/单细胞观察、动物干预、体外实验和计算假设。
3. **模型翻译**：说明文献中的现象怎样被压缩成 Agent、场或概率规则。
4. **参数地位**：区分文献支持的方向与未校准的数值系数。
5. **反例与边界**：保留癌种、时相和实验系统依赖性，不把相关性写成普遍因果。

## 2. 证据等级

| 等级 | 含义 | 在本项目中的用法 |
|---|---|---|
| A | 人体组织、空间成像或单细胞证据，并有功能研究呼应 | 支持状态存在、空间关系或异质性 |
| B | 动物模型中直接干预并观察到功能变化 | 支持机制方向和反馈关系 |
| C | 体外、三维培养或类器官直接实验 | 支持局部细胞行为和扩散/力学规则 |
| D | 建模约定或教学抽象 | 必须显式标为未校准，不能作生物定量解释 |

## 3. 机制审计表

### 3.1 血管供氧、细胞消耗与扩散形成空间氧梯度

- **证据层级**：人肿瘤组织观察 + 多细胞球实验
- **来龙去脉**：肿瘤组织和三维细胞球可形成从血管/外周向内部下降的供氧梯度，并伴随低增殖区和坏死核心。
- **代码中的翻译**：氧气从血管线段输入，在二维网格中扩散并被细胞消耗；长期低氧增加应激与坏死概率。
- **不能外推的部分**：二维扩散、统一耗氧和“天”单位均是抽象；没有显式 HIF、灌注动力学或氧分压单位。
- **核心文献**：[THOMLINSON1955]、[FREYER1988]

### 3.2 空间拥挤与机械限制抑制增殖

- **证据层级**：三维肿瘤球直接实验支持
- **来龙去脉**：肿瘤球中的压缩应力和体积限制可降低核心增殖，外周保留更高增殖活性。
- **代码中的翻译**：癌细胞只有在邻域存在空位时分裂；高邻居数使其进入拥挤静息并降低周期推进。
- **不能外推的部分**：网格占位不是组织力学模型，不计算压力张量、黏附、细胞形变或侵袭。
- **核心文献**：[DELARUE2014]

### 3.3 药物从血管进入并受距离与基质影响

- **证据层级**：三维培养与异种移植直接测量
- **来龙去脉**：多种抗癌药在组织中的暴露会随离血管距离下降；部分药物在实体瘤中的穿透范围有限。
- **代码中的翻译**：药物由血管脉冲输入后扩散、衰减和被局部环境限制；高基质减慢扩散。
- **不能外推的部分**：“细胞毒性治疗”是抽象类别，不对应任何具体药物、药代动力学、剂量或给药途径。
- **核心文献**：[KYLE2004]、[KYLE2007]、[PROVENZANO2012]

### 3.4 T 细胞依赖迁移、接触与重复杀伤

- **证据层级**：活体成像与单细胞观察
- **来龙去脉**：活体双光子成像可直接观察 CD8 T 细胞与肿瘤细胞稳定接触和细胞毒性事件。
- **代码中的翻译**：T 细胞移动寻找邻近癌细胞，接触后按识别、环境和功能状态计算杀伤；攻击消耗能量并可重复发生。
- **不能外推的部分**：未显式模拟抗原呈递、TCR 克隆、免疫突触、穿孔素/颗粒酶或旁观者杀伤。
- **核心文献**：[BREART2008]

### 3.5 持续肿瘤刺激和抑制环境降低 T 细胞功能

- **证据层级**：动物肿瘤单细胞与表观遗传实验
- **来龙去脉**：肿瘤特异性 T 细胞可进入不同程度的功能障碍状态，部分早期状态具有可塑性，而深度功能障碍更难逆转。
- **代码中的翻译**：exhaustion 连续积累并降低激活、迁移和杀伤；免疫激活只能部分、短时缓解，不凭空增加浸润。
- **不能外推的部分**：单一 exhaustion 数值压缩了多种功能障碍程序，不等同于临床检查点标志物或治疗反应。
- **核心文献**：[PHILIP2017]

### 3.6 治疗优先清除敏感细胞，改变克隆竞争与相对组成

- **证据层级**：细胞/动物进化研究与预临床干预
- **来龙去脉**：耐药可由治疗前存在的亚克隆被选择，也可经药物耐受状态继续演化；保留敏感竞争者的进化策略在部分预临床模型中延长了控制。
- **代码中的翻译**：初始场景包含低比例耐受克隆及适应度代价；治疗后敏感克隆减少、空间释放，耐受克隆相对扩张。
- **不能外推的部分**：模型不是适应治疗处方工具；克隆性状和竞争系数未按癌种或患者校准。
- **核心文献**：[HATA2016]、[ENRIQUEZ2016]

### 3.7 性状漂移是可关闭的探索性简化，不是主要耐药来源

- **证据层级**：模型假设，受肿瘤进化研究启发
- **来龙去脉**：真实耐药可来自预存遗传变异、获得性改变和非遗传可塑性；不同路径具有不同后续生物学。
- **代码中的翻译**：默认主要展示预存克隆的选择；低概率“性状漂移”只允许在高级参数中改变克隆身份。
- **不能外推的部分**：该操作不能解释为某个具体突变发生，也不能据此估计突变率或耐药风险。
- **核心文献**：[HATA2016]

### 3.8 巨噬细胞采用连续功能轴，而非硬性 M1/M2 二分

- **证据层级**：人体单细胞证据 + 模型抽象
- **来龙去脉**：肿瘤内髓系细胞呈现连续、混合且组织依赖的转录状态，经典标记并不总能形成互斥类别。
- **代码中的翻译**：每个巨噬细胞使用 activation ∈ [-1, 1]：负值偏炎症/免疫支持，正值偏免疫抑制/修复；局部缺氧、抑制信号、炎症与吞噬死亡细胞使该值连续变化。
- **不能外推的部分**：该轴只压缩功能方向，不代表任何真实命名亚群，也不能映射到患者样本中的精确细胞比例。
- **核心文献**：[AZIZI2018]

### 3.9 缺氧区募集并重塑巨噬细胞功能

- **证据层级**：动物模型直接实验支持
- **来龙去脉**：阻止巨噬细胞进入缺氧肿瘤区域可降低其促血管与免疫抑制功能，并改变肿瘤进展。
- **代码中的翻译**：巨噬细胞趋向坏死、炎症和低氧区域；持续低氧使功能轴向抑制/修复方向偏移，并产生有限的血管支持场。
- **不能外推的部分**：模型没有显式模拟 Sema3A/Nrp1、HIF 或具体细胞因子，血管支持仅为定性反馈。
- **核心文献**：[CASAZZA2013]、[LIN2006]

### 3.10 巨噬细胞可构成 T 细胞进入与接触肿瘤细胞的障碍

- **证据层级**：人组织相关 + 动物干预证据
- **来龙去脉**：部分肿瘤中，巨噬细胞富集与 CD8 T 细胞难以进入肿瘤巢相关；干预巨噬细胞可改善 T 细胞接触和抗 PD-1 反应。
- **代码中的翻译**：T 细胞附近的抑制型巨噬细胞形成局部 barrier 值，降低迁移速度、激活与杀伤概率。
- **不能外推的部分**：这是空间和功能的合并抽象，不能解释为巨噬细胞在所有癌种中都产生同等程度的排斥。
- **核心文献**：[PERANZONI2018]

### 3.11 死亡细胞清除会改变炎症与巨噬细胞状态

- **证据层级**：体外/动物模型直接实验支持
- **来龙去脉**：巨噬细胞吞噬凋亡肿瘤细胞可推动修复性、促肿瘤功能；治疗后的死亡细胞处理异常也可形成免疫抑制残余环境。
- **代码中的翻译**：巨噬细胞会清除邻近碎片；吞噬降低短期炎症，但增加 efferocytosisMemory，并使功能轴向抑制/修复方向移动。未及时清除的坏死碎片持续释放炎症。
- **不能外推的部分**：模型不区分全部死亡方式、吞噬受体与下游代谢，只保留“清除—炎症消退—功能重塑”关系。
- **核心文献**：[SOKI2014]、[WERFEL2019]

### 3.12 成纤维细胞保留多维功能，不做单一 CAF 开关

- **证据层级**：类器官/动物模型及分子机制证据
- **来龙去脉**：CAF 可表现出空间和信号依赖的炎症型、肌成纤维样等不同程序，IL-1/JAK/STAT 与 TGFβ 等信号可塑造其状态。
- **代码中的翻译**：每个成纤维细胞独立保存 activation、matrixActivity 与 exclusionActivity；三者可不同步变化。
- **不能外推的部分**：模型没有给细胞硬贴 iCAF/myCAF 标签，也未覆盖抗原呈递 CAF 等更多亚型。
- **核心文献**：[OHLUND2017]、[BIFFI2019]

### 3.13 成纤维细胞重塑基质，影响运动、灌注与药物可及性

- **证据层级**：人组织观察 + 动物干预证据
- **来龙去脉**：肿瘤间质结构与 T 细胞定位和迁移有关；高间质压力与基质可限制灌注和药物到达，针对特定基质组分可改善递送。
- **代码中的翻译**：活化成纤维细胞在邻域沉积简化 matrix 场；该场降低 T 细胞移动并减慢药物扩散。
- **不能外推的部分**：matrix 是胶原、透明质酸、纤连蛋白、力学与几何结构的合并量，不代表某一种 ECM 浓度。
- **核心文献**：[SALMON2012]、[PROVENZANO2012]

### 3.14 CAF 相关信号可促进免疫排斥

- **证据层级**：动物模型与临床样本关联证据
- **来龙去脉**：FAP+ CAF 来源的 CXCL12 以及成纤维细胞 TGFβ 程序与 T 细胞排斥和免疫治疗反应受限有关。
- **代码中的翻译**：exclusionActivity 提高局部 suppression，并与 matrix 一起降低 T 细胞进入和功能。
- **不能外推的部分**：模型不把 CXCL12 或 TGFβ 当作唯一机制，也不预测检查点治疗疗效。
- **核心文献**：[FEIG2013]、[MARIATHASAN2018]

### 3.15 基质干预采用“正常化”而不是无限清除

- **证据层级**：相互制约的动物模型证据
- **来龙去脉**：在胰腺癌模型中，某些基质成分可限制肿瘤；强力耗竭肌成纤维细胞/纤维化可能增加免疫抑制并加速疾病。
- **代码中的翻译**：“基质正常化”暂时降低过度沉积和免疫排斥，但不删除成纤维细胞，也设置下限，避免把全部间质清除定义为必然获益。
- **不能外推的部分**：这些关键反例主要来自 PDAC，跨癌种推广必须谨慎；模拟只用于展示双向性。
- **核心文献**：[RHIM2014]、[OZDEMIR2014]

### 3.16 所有数值系数均标注为未校准模型参数

- **证据层级**：模型设计声明
- **来龙去脉**：文献支持的是机制方向和上下文依赖性，而不是本项目中每个归一化系数的具体数值。
- **代码中的翻译**：UI 显示 0–100 的相对强度；内部时间、浓度、概率和距离均为无量纲或模拟单位，并通过固定种子、边界测试与敏感性测试控制一致性。
- **不能外推的部分**：不得把数值解释为患者浓度、细胞密度、药物剂量、真实天数或疗效概率。
- **核心文献**：无：模型设计声明

## 4. Agent 与场变量定义

### 4.1 癌细胞

- 保存克隆、生命值、细胞周期、损伤、应激与状态。
- 分裂需要可用空间；局部氧气、药物、拥挤和克隆性状共同影响周期与死亡。
- 三个预设克隆是教学用生态权衡，不代表具体癌种分子亚型。

### 4.2 T 细胞

- 保存激活、耗竭、能量、杀伤计数和局部环境。
- 迁移与接触杀伤是空间化的；高基质、免疫抑制及抑制型巨噬细胞邻域降低功能。
- “免疫激活”只短时缓解功能抑制，不创造新的 T 细胞或预测检查点抑制剂疗效。

### 4.3 巨噬细胞

- 使用 `activation ∈ [-1,1]` 的连续功能轴，而不是 M1/M2 二分。
- 会向死亡细胞和肿瘤区域迁移，执行凋亡/坏死碎片清除。
- 吞噬凋亡碎片形成 `efferocytosisMemory`，倾向修复/抑制方向；坏死碎片更偏炎症输出。
- 低氧与抑制背景可增加局部免疫障碍和血管支持场。

### 4.4 成纤维细胞

- 分开保存 `activation`、`matrixActivity`、`exclusionActivity`。
- 活化可产生局部基质和免疫排斥场，但三个程序不强制同步。
- “基质正常化”降低过度输出，不删除细胞，也不允许把间质归零。

### 4.5 环境场

| 场 | 来源 | 作用 | 模型地位 |
|---|---|---|---|
| oxygen | 血管供应、扩散、细胞消耗 | 影响增殖、应激与坏死 | 归一化相对量 |
| drug | 血管脉冲、扩散、衰减 | 对不同克隆产生不同损伤 | 抽象药物类别 |
| matrix | 初始组织与 CAF 沉积 | 限制细胞移动和药物扩散 | ECM 合并量 |
| suppression | 初始背景、CAF 与巨噬细胞输出 | 降低 T 细胞激活与杀伤 | 多因子合并量 |
| inflammation | 坏死、炎症侧巨噬细胞 | 趋化与功能重塑 | 多因子合并量 |
| angiogenic | 低氧背景下抑制侧巨噬细胞 | 对局部血管供应提供有限正反馈 | 定性抽象 |

## 5. 参数来源与数值地位

### 5.1 文献支持什么

文献支持的是方向关系，例如“离血管更远时药物暴露可能下降”“致密间质可限制运动和递送”“持续刺激可导致 T 细胞功能障碍”“低氧区巨噬细胞可表现出促血管/抑制功能”。

### 5.2 文献不支持什么

文献并不直接给出本项目中的 `0.018`、`0.62`、`5.2 天` 或滑块 `42%`。这些数值是为了形成稳定、可观察、可复现的教学动力学而设定的无量纲系数。

### 5.3 控件解释

| 控件 | 正确解释 | 错误解释 |
|---|---|---|
| 血管供氧 0–120 | 场景中的相对供氧强度 | mmHg、血氧饱和度 |
| 基质密度 0–100 | 综合扩散/运动阻力 | 胶原或透明质酸浓度 |
| 免疫抑制 0–100 | 多种抑制机制的综合背景 | TGFβ、PD-L1 等单一分子值 |
| T 细胞浸润 0–100 | 相对进入频率 | 每 mm² 细胞数 |
| 巨噬细胞募集 0–100 | 相对招募概率 | 单核细胞临床计数 |
| 成纤维细胞活化 0–100 | 综合活化驱动力 | αSMA 或特定基因表达量 |
| 性状漂移率 | 探索性随机状态变化强度 | 突变率/碱基/分裂 |
| 治疗剂量 | 模拟暴露强度 | mg/m² 或真实处方 |

## 6. 更新顺序与因果约束

每个 tick 使用固定顺序：环境供应/扩散 → 癌细胞 → T 细胞 → 巨噬细胞 → 成纤维细胞 → 碎片 → 治疗衰减 → 事件与指标。固定顺序是复现与测试需要，不主张真实组织存在同样的离散先后。

关键约束包括：浓度不小于 0；连续状态保持在定义区间；死亡细胞不能再次分裂；固定种子和固定输入给出一致结果；“基质正常化”不删除 CAF；治疗主要通过选择预存性状改变克隆组成。

## 7. 验证策略

- **确定性测试**：同种子、同输入产生一致克隆与场结果。
- **边界测试**：全部场值与细胞状态保持合法范围。
- **机制单元测试**：吞噬碎片增加吞噬记忆；CAF 增加局部基质；正常化不删除 CAF。
- **场景回归**：治疗产生初始下降、选择压力与可观察反弹。
- **敏感性要求**：发布前应对关键系数做单因素和全局敏感性分析，报告哪些结论对参数稳健。

## 8. 当前尚未完成的科学验证

1. 未用同一癌种的空间病理或空间组学数据进行参数拟合。
2. 未用独立实验数据集做定量外部验证。
3. 未进行结构不确定性比较，例如不同趋化、扩散或死亡方程的模型选择。
4. 未模拟具体药物 PK/PD、特定细胞因子、抗原谱、淋巴系统或器官尺度灌注。
5. 未覆盖巨噬细胞和 CAF 的全部谱系来源、亚群和时空转换。

因此，当前版本属于**证据约束的概念模型**，不是经过生物学定量校准和预测验证的研究模型。
