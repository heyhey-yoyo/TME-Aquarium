# TME Aquarium v1.1.0 科学事实、UI、地图与教育设计审查

- 审查日期：2026-08-03
- 审查对象：`TME_Aquarium_v1.1.0_2026-08-04.zip`
- 改良交付版本：`TME Aquarium v1.1.1 科学表达与教学 UI 审校版`
- 核心模拟模型版本：仍为 `1.1.0`，保持 v2 存档兼容

## 一、结论

原项目**没有发现会颠倒核心肿瘤微环境机制方向的重大科学事实错误**。它对氧扩散与缺氧、药物组织穿透、机械拥挤、T 细胞接触杀伤、克隆选择、巨噬细胞和 CAF 异质性、基质免疫排斥及间质双重作用的总体表述是合理的；而且已经具备较好的证据卡、文献追踪、模型假设和不可外推边界。

项目最需要修正的不是“把错误知识改成正确知识”，而是防止用户把**无量纲教学代理量**误读成真实的生理量、临床剂量或时间尺度。原界面中的“第 X 天”“剂量”“毒性”“突变率”和百分比式展示，容易产生一种参数已经完成实验或临床校准的视觉印象。另有几处复杂免疫生物学被压缩为单轴或单变量，方向上可用于教学，但应更清楚地说明其局限。

综合判断：

- 作为**机制性教育模拟器**：基础扎实，可继续发展。
- 作为**定量科研模型**：尚未进行外部数据拟合、参数估计、全局敏感性分析和不确定性量化。
- 作为**临床工具**：不适用，也不应从当前输出推导药物选择、剂量、疗效或患者预后。

## 二、科学审查结果

### 1. 氧气、缺氧和坏死

**总体方向合理。** 血管附近氧场较高、远离供氧源后下降，肿瘤细胞耗氧并在低氧和拥挤环境中承受应激，是适合二维教学模型的机制抽象。

需要注意：

- `oxygen < 0.24` 只是归一化场中的内部阈值，不能解释成某个固定的组织 pO₂。
- “缺氧面积”若直接显示百分比，容易被理解为影像或病理测量值；更准确的名称是“低氧代理面积”。
- “模拟日”并未映射到真实细胞周期、药代或肿瘤生长时间。
- 当前没有显式的灌注动力学、血红蛋白携氧、HIF 通路、乳酸和 pH。

**改良处理：** 已将指标改为“低氧代理面积”，注明“归一化氧场 < 0.24（非 pO₂）”；地图增加低氧代理边界和连续色标，并在地图上标明“模拟坐标、无物理尺度”。

### 2. 药物穿透和治疗反应

**总体方向合理。** 从血管附近形成药物代理场、基质降低组织暴露、敏感细胞先下降而耐药亚克隆随后富集，符合实体瘤空间穿透和选择压力的教学叙事。

需要注意：

- 当前药物场不是浓度，也没有单位。
- “剂量”没有药代动力学或药效学映射。
- “累计毒性”不是器官毒性、CTCAE 分级或患者风险。
- 细胞死亡概率和治疗时序属于演示参数，不能转换为临床疗效。

**改良处理：** 已将“剂量”改为“相对强度”，治疗改为“抽象细胞毒性脉冲”，药物图层改为“药物代理”，累计毒性改为“系统代价（代理）”。

### 3. T 细胞功能和耗竭

**接触杀伤、迁移受抑制场与基质影响、持续刺激和代谢压力降低功能的方向合理。**

主要简化是模型用一个 `exhaustion` 标量同时承载多种含义。真实肿瘤内 CD8 T 细胞并非从“活跃”平滑滑向单一终点，而存在具有自我更新能力的前体/干样耗竭群体、过渡群体和终末耗竭群体；不同状态对免疫检查点治疗的反应也不同。因此：

- 当前变量更适合称为“功能障碍代理”，而不是完整的耗竭谱系。
- 免疫增强后降低该标量，应解释为部分功能恢复或环境压力缓解，而不是终末耗竭被完全逆转。
- 当前没有抗原特异性、克隆扩增、TCR 亲和力、树突细胞激活和检查点分子层。

**改良处理：** 检查器中已使用“功能活性代理”和“功能障碍代理”；证据说明中补充前体耗竭与终末耗竭的区别及不可完全逆转边界。

### 4. 炎症与免疫抑制

原规则把“炎症”较多地作为 T 细胞激活和能量支持信号。作为课堂上的“促炎/抗肿瘤信号”代理可以成立，但“炎症”在肿瘤中高度依赖来源、持续时间和细胞因子组合；慢性炎症也可能促进免疫抑制、组织重塑和肿瘤进展。

建议未来将单一炎症场拆为至少两个概念：

1. 急性免疫激活/趋化信号；
2. 慢性损伤与免疫抑制性炎症。

本次没有改动核心模拟方程，以免改变既有场景和存档行为；已在证据边界中加入“慢性炎症不一定有利于抗肿瘤免疫”的说明。

### 5. 巨噬细胞

**用连续功能轴代替简单 M1/M2 二分法，是原项目的优点。** 吞噬凋亡碎片后产生清除记忆、低氧环境促进促肿瘤/血管支持特征、巨噬细胞限制 T 细胞接近肿瘤，这些方向都具有合理的文献基础。

需要注意：

- 一个 `[-1, 1]` 轴仍然压缩了真实 TAM 的多维转录、代谢和空间状态。
- 证据说明提到巨噬细胞进入低氧区，但当前移动规则主要趋向碎片或癌细胞；低氧主要改变功能轴，并未完整实现显式低氧趋化。这属于“文字覆盖范围略大于代码实现”的不一致。
- 吞噬后的免疫效应与碎片类型、死亡方式和环境有关，不能总是视作同一方向。

**改良处理：** 证据卡中明确单轴是多维状态的压缩，并说明当前移动规则没有完全解析低氧趋化。下一模型版本可增加低氧/炎症梯度权重，而不是在文案中暗示已完整实现。

### 6. CAF、基质和间质双重作用

**这是项目科学表达较强的一部分。** CAF 活化、基质沉积、T 细胞空间排斥、药物暴露下降和 CAF 异质性均有合理方向；项目也正确提示了间质并非永远“越少越好”，因为某些间质成分可能限制肿瘤扩张，粗暴清除可能产生不利结果。

需要注意：

- 单一基质场同时代表 ECM 密度、几何阻力、机械压力和扩散障碍，属于聚合代理。
- CAF 的炎症型、肌成纤维型、抗原呈递型等状态未被分别表示。
- “基质正常化”不应被解读为现实治疗方案或适用剂量。

**改良处理：** 参数名称改为“基质阻力”，并说明它是 ECM、力学和几何屏障的聚合代理；保留了间质双重作用的边界声明。

### 7. 克隆演化与“突变率”

预存敏感、耐药和低氧耐受亚克隆在治疗压力下发生频率变化，是合理的选择过程演示。问题在于原“突变率”变量实际上更接近低概率的性状或身份漂移，并不对应 DNA 突变率、突变谱或获得性耐药机制。

**改良处理：** 已改为“性状漂移强度”，并明确“不等于生物突变率”。建议继续以预存克隆选择为主要教学机制，把新生耐药作为高级探索选项。

## 三、风险分级

| 级别 | 结果 | 说明 |
|---|---|---|
| 严重 | 未发现 | 未发现会把核心机制方向完全讲反、或直接给出临床治疗建议的问题。 |
| 较高 | 量纲与临床感错觉 | “天、剂量、毒性、突变率、百分比”看起来比实际校准程度更强。 |
| 中等 | 复杂状态压缩 | T 细胞耗竭、巨噬细胞状态、CAF 状态和炎症被压缩为单轴或单场。 |
| 中等 | 文案—实现偏差 | 巨噬细胞低氧趋化的证据说明超过当前显式移动规则。 |
| 较低 | 地图解释不足 | 原环境图层缺少连续色标、阈值边界、坐标性质和尺度声明。 |
| 较低 | 教学闭环不足 | 原项目可探索性强，但缺少“提出假设—控制变量—观察指标—解释限制”的引导。 |

## 四、已实施的改良

### 1. 科学表达

- 顶部增加“机制教学模型 · 参数未校准”。
- “第 X 天”统一改为“模拟日”。
- 供氧、免疫抑制、浸润、募集、活化等均改为“强度”或“倾向”。
- 所有容易被理解为真实浓度或剂量的输出使用 `a.u.`、`/100` 或“代理”字样。
- “缺氧面积”改为“低氧代理面积”。
- “突变率”改为“性状漂移强度”。
- 细胞检查器把 T 细胞状态改为“功能活性代理/功能障碍代理”。
- 证据卡补充耗竭谱系、TAM 多维状态、低氧趋化实现边界和慢性炎症双向性。

### 2. UI 信息层级

- 把科学边界放在首屏，而不是只藏在帮助或文档中。
- 参数标题与解释分层：变量名、教学含义、不可外推边界同时可见。
- 干预按钮使用“抽象脉冲”“代理提升”等表述。
- 指标卡强化单位属性，减少“精确数字即真实测量”的错觉。
- 保留深色实验室视觉，但让关键文字、徽章和读数更清楚。

### 3. 地图设计

- 增加“空间代理图 · 模拟坐标 · 无物理尺度”标识。
- 环境场增加连续色标，不再只靠整体色调猜测强弱。
- 增加可开关的低氧代理虚线边界。
- 增加淡化模拟坐标网格，帮助比较空间位置，但不伪装成真实毫米尺度。
- 血管线条以粗细、透明度和虚实表达灌注/稳定性代理。
- 保留不同细胞的形状差异，避免完全依赖颜色。
- 修复死亡碎片颜色条件中“药物损伤/药物诱导死亡”的字符串不一致。

### 4. 教育设计

新增三组科学观察任务：

1. **血管距离与低氧核心**：改变供氧强度，观察低氧代理边界和细胞应激。
2. **基质与免疫排斥**：提高基质阻力，比较 T 细胞进入肿瘤区域的趋势。
3. **治疗压力与克隆选择**：记录治疗前后总负荷和耐药克隆比例，区分“短期缩小”与“长期生态选择”。

每组任务采用“问题—操作—读数—解释边界”的结构，目标是让用户学习控制变量和因果谨慎，而不是只追求把肿瘤清零。

## 五、建议的下一阶段升级

### 优先级 A：提升科学模型结构

1. 将 T 细胞的单一功能障碍变量拆为：可逆功能抑制、前体耗竭倾向、终末分化倾向。
2. 将“炎症”拆为急性免疫激活信号与慢性免疫抑制性炎症。
3. 为巨噬细胞增加显式的低氧、碎片、癌细胞和炎症多梯度趋化权重，并在 UI 显示其当前主导线索。
4. 将 CAF 至少拆成基质重塑倾向和炎症/趋化因子倾向两个轴。
5. 将基质扩散障碍和机械压力分为不同场，避免一个变量承担过多机制。

### 优先级 B：提升实验教学

1. 增加左右并排的“对照组/干预组”，共享随机种子和初始状态。
2. 在实验结束后自动生成证据表：操作变量、保持不变变量、主要结果、是否支持假设、不能得出的结论。
3. 增加“反事实重播”：从同一时间点分叉施加不同干预。
4. 为每个场景给出预期的**定性方向**，但不预告精确数值。
5. 增加参数敏感性小面板，提醒用户单次随机运行不等于稳定结论。

### 优先级 C：提升视觉与无障碍

1. 对所有环境色板进行常见色觉缺陷模拟和对比度测试。
2. 图层同时使用颜色、纹理和轮廓编码；尤其是克隆图层不能只靠相近色相。
3. 增加肿瘤主体的包络轮廓、血管最近距离读数和局部探针。
4. 鼠标悬停时显示局部氧场、基质、抑制和药物代理的迷你雷达或条形图。
5. 小屏模式优先保留地图、核心指标和当前实验任务，把高级参数折叠到次级面板。

### 优先级 D：若要用于科研

必须另立“定量研究版”，并完成：

- 明确癌种、实验体系和空间尺度；
- 用体外/动物/患者数据校准参数；
- 给出参数后验或置信区间；
- 全局敏感性与可辨识性分析；
- 外部验证和预注册的预测任务；
- 将教育参数与校准参数在代码和界面上完全隔离。

## 六、验证结果

改良版完成以下检查：

- `npm test`：15/15 通过。
- `npm run audit`：六个场景均可稳定运行至 600 步，没有明显整体清零、数值越界或参数爆炸。
- 所有 JS/MJS 文件通过 `node --check`。
- HTML 共 82 个 ID，无重复；新增关键控件均存在。
- 核心 `src/simulation.js` 未因本次 UI/科学表达审校而改写，因此原有固定种子和 v2 存档兼容性保持不变。

限制：当前执行环境中的 Chromium 启动受到系统策略/DBus 条件影响，未完成可靠的真实浏览器截图和逐项点击冒烟测试。交付前仍建议在 Chrome、Edge 或 Firefox 中人工检查：首屏布局、图层切换、低氧边界开关、三组引导实验、窄屏布局、离线缓存与导出功能。
